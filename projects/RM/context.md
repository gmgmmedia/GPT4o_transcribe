# Project: RM (RealMotion)

## Topic
Crypto podcast/interview series.
- Episodes RM-7 through RM-9: Stellar (blockchain network) representative
- Episodes RM-10 through RM-12: Aptos (Layer 1 blockchain) representative

## Speakers
- Speaker A: Host (interviewer)
- Speaker B: Guest (Stellar rep for RM-7-9, Aptos rep for RM-10-12, Monad rep for RM-13-14, Algorand rep for RM-15-16)

## Terminology
### Stellar (RM-7 to RM-9)
- Stellar: Blockchain network / payment protocol
- XLM: Stellar Lumens (native token)
- Soroban: Stellar's smart contracts platform
- Anchors: Entities that bridge between Stellar and traditional finance
- SDF: Stellar Development Foundation

### Aptos (RM-10 to RM-12)
- Aptos: Layer 1 blockchain (Move language)
- APT: Aptos native token
- Move: Programming language used by Aptos (originally from Meta/Diem)
- Aptos Labs: Core development team
- Block-STM: Aptos parallel execution engine

### Monad (RM-13 to RM-14)
- Monad: High-performance EVM-compatible Layer 1 blockchain
- MON: Monad native token
- MonadBFT: Monad's consensus mechanism
- Monad Labs: Core development team
- Parallel execution: Monad's approach to transaction processing
- EVM: Ethereum Virtual Machine (compatibility layer)
- TPS: Transactions per second

### Algorand (RM-15 to RM-16)
- Algorand: Layer 1 blockchain (Pure Proof-of-Stake)
- ALGO: Algorand native token
- AVM: Algorand Virtual Machine
- ASA: Algorand Standard Assets
- Algorand Foundation: Governance and ecosystem development
- Algorand Inc: Core development company
- PPoS: Pure Proof-of-Stake (Algorand's consensus)
- Silvio Micali: Algorand founder (MIT professor, Turing Award)
- ABI: Application Binary Interface
- PyTEAL: Python library for writing Algorand smart contracts
- Algofi: Algorand DeFi protocol
- Tinyman: Algorand DEX
- Folks Finance: Algorand lending protocol
- x402: HTTP 402 Payment Required protocol for agent-to-agent commerce
